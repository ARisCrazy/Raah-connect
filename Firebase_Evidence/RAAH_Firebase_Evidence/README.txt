RAAH Connect Firebase Evidence
==============================

Firebase Project:
RAAHconnect

Purpose:
This package contains a documentation-oriented export
of the Firestore data used by the RAAH Connect project.

Firestore Collections:
- users
- ambulances
- emergencyRequests
- assignments
- hospitals
- hubs

The exported records are development/test data and are
intended for MCA project documentation and implementation
verification.

This package does NOT contain Firebase credentials,
service-account private keys, passwords, or API secrets.

Realtime Database is not included in this export.
